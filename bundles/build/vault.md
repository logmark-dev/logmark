# Build something

## Purpose
A working vault for the project I'm shipping - code, decisions, architecture, problems I'm chewing on. The vault tracks the shape of the work and the choices that compose it.

## Scope
INCLUDE: code captures, debugging notes, architecture decisions, build and CI observations, refactor ideas, anything tagged to a +project. EXCLUDE: unrelated personal life, generic life admin.

## How agents should help
Be terse. Don't explain code I already wrote. Surface stuck blocks older than three days and decisions that connect across projects. Skip motivational framing.

## Frozen vault-level decisions
Local-first; nothing leaves the machine without a reason. Capture is unintrusive - agents do not interrupt a flow.

## Don't surface
Trivial typos, minor formatting tweaks, low-signal log noise.
