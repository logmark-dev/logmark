# Source vault

## Purpose
I feed this vault with links, PDFs, screenshots, transcripts - and agents organise them into concepts and connections. I curate the sources; agents do the structural work.

## Scope
INCLUDE: source materials (links, PDFs, screenshots, transcripts), brief notes about why a source matters, agent-extracted concept notes attributed via source: notation. EXCLUDE: personal log entries (use a Daily journal vault), code captures (use a Build or Code-context vault).

## How agents should help
Extract concepts from sources I drop in _inbox/. Cross-link concepts that appear across sources. Maintain provenance: every agent-authored note carries source: agent:<name>. Flag sources I haven't returned to.

## Don't surface
Sources I've explicitly tagged #archive.
