# ViewBlock schemas

Contract surface for the ViewBlock envelope. Spec: [docs/reference/viewblock-envelope-spec.md](../../docs/reference/viewblock-envelope-spec.md).

- `npm run generate-viewblocks` - regenerate `block-types.json` + the envelope enum from the TS union (normative source)
- `npm run validate-viewblocks` - validate every fixture against its schema + registry three-way sync
